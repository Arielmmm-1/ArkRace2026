# Ark_Race2026
2026第五届方舟计划机器人大赛 | 智能竞速机器人 全套复盘总结

## 📌 整车基础参数
- 参赛赛事：第五届方舟计划机器人大赛
- 整车重量：5.7kg（含遥控器全套设备）
- 设备定位：麦轮全向移动 + 升降传送 + 球体夹取作业机器人

---

## ⚙️ 一、硬件选型问题复盘
### 1. 驱动电机
- 核心问题：前期未精准计算整车负载扭矩，电机扭矩余量严重不足
- 实际表现：整车负重后速度疲软、动力不足、加速拖沓
- 结构不匹配：该电机轴径小、原生不适配大直径车轮，重载工况非常吃力
- 迭代方案：后续可更换 24V 520 / 550 大扭矩电机，适配重载大轮场景

### 2. 法兰联轴器
- 现状：电机轴仅4mm，市面仅能匹配小型单面法兰联轴器
- 致命缺陷：大麦轮自重+惯性大，仅靠单颗六角螺母锁止完全不够
- 实战问题：全向平移时车轮微震、螺丝松动、长期运行极易掉轮
- 优化方向：后续必须采用双锁紧结构+顶丝加固，杜绝松脱隐患

### 3. 主控板子（嘉立创天空星 F407VET6）
- 优点：F407芯片资源充足、主频、外设、内存完全满足比赛需求
- 事故问题：调试期间两次开发板烧毁
- 疑似原因：带电插拔、不断电操作导致瞬间电压冲击击穿
- 规范整改：后续所有接线、插拔、改装必须全程断电操作

---

## 🏗️ 二、底盘结构设计缺陷
### 1. 平板式底盘
- 结构短板：纯平面薄板底盘，不适合大尺寸、大重量车体
- 实际问题：整车5.7kg负重后底盘下沉形变，车轮倾角偏移
- 核心痛点：麦轮全向解算极度依赖结构刚性，形变误差软件完全无法补偿
- 经验总结：平板底盘仅适合小型轻量化小车，重载赛事必须采用铝型材框架结构

---

## 📐 三、升降传送机构重大设计问题
### 1. 单边受力倾覆问题
- 结构硬伤：升降横梁左侧承载负载，产生巨大下压倾覆力矩
- 受力畸形：动力源集中在最右侧，受力点严重不对称
- 直接后果：光轴滑块卡顿、升降不顺、结构偏斜

### 2. 悬臂过长、传动损耗极大
- 数据：左侧伸出长度超350mm，属于超长悬臂结构
- 问题：传送带动力传递末端损耗严重
- 现状：仅能勉强稳定运送150g小球，负载上限低、稳定性差

### 3. 竖直立柱无闭环固定
- 设计漏洞：两根500mm高竖杆顶部无固定框架，未形成刚性矩形闭环
- 运动缺陷：车体一动，立柱整体高频抖动、振幅极大
- 设计反思：错误认为底部横梁可单独稳定立柱，完全忽略竖向悬臂刚度问题

### 4. 步进电机固定方案简陋
- 现状：前期未预留标准安装孔位
- 临时方案：仅靠胶水+扎带固定，刚性极差、极易松动
- 改进：后续结构建模优先预留电机固定座、孔位、加强筋

### 迭代优化思路
- 将传送驱动轴居中布置，右侧改为纯支撑光轴，弱化单边倾覆力
- 单根导向杆采用双滑块结构，大幅提升承载稳定性
- 依托2020铝型材T槽做模块化拼装，配合精准建模替代手量拼装
- 多参考成熟赛事机器人受力结构，避免纯凭感觉设计

---

## 🤌 四、末端夹取机构总结
- 现状：舵机夹爪为赛前紧急采购配件，临时救急方案
- 优点：常规抓取表现尚可，适配比赛基础需求
- 缺陷：夹爪行程不足，无法包覆半个球体，抓取容错率低
- 后续升级方向：气动夹爪 / 磁吸抓取结构，稳定性、负载能力全面升级

---

## 🎯 五、全局复盘 &amp; 后续优化总纲
- 前期必须完成：扭矩计算、负载测算、悬臂受力分析，再定稿结构
- 长悬臂结构必须做闭环刚性框架，杜绝抖动形变
- 车轮、联轴器必须做防松、锁紧、加固设计
- 调试规范标准化，严禁带电插拔，保护主控硬件
- 执行器、关键结构提前选型、提前建模、提前测试，杜绝赛前临时拼凑
